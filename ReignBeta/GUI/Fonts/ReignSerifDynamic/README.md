# ReignSerifDynamic

`ReignSerifDynamic` is the live Gauntlet font alias for genuinely dynamic Reign UI text. Fixed interface typography is intentionally baked into the approved shell artwork and must not be recreated as runtime text.

The alias uses a Cormorant Garamond Medium 4.002 SDF atlas generated with TaleWorlds' FontAtlas tool. Source, license, generator settings, and hashes are recorded in `artwork/ui-modern-style-kit/font-sources/provenance.json`.
