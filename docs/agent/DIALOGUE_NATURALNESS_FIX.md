## Production behavior

- A shared conversation contract applies to individual, party and social-event requests. It permits direct ordinary conversation, preserves individual temperament and refusal, distinguishes an acknowledged answer from a separate outstanding request, treats old comprehension as fallible interpretation, and discourages group members from repeating another speaker's lecture.
- Exact reviewed universal tone clauses are scoped when composing loaded templates as well as in shipped defaults. Saved prompt bytes and unfamiliar surrounding customization remain intact. This applies after installation without relying on a user resetting prompts. Existing prompt retirement rules remain separate.
- Clarification, correction and apology hints survive prompt compaction and apply after serial or parallel preparation. These are limited English-language hints, not authoritative classifications of player intent.
- The continuity repair detects repeated conversational-accounting patterns, including paraphrases with little four-word overlap. It uses recent attributed NPC history; group echoes require another speaker after the exact current player message. One isolated metaphor is allowed. A repeated metaphor plus a third-or-later conversational tally is also detected. Explicit requests about quantities, financial matters and military/inventory counts bypass this added heuristic. Existing factual guards still apply.
- A substantive loop prevents the stage-direction-only shortcut. The existing bounded repair receives recent shared dialogue and rules for correcting dependent private state. Its existing second-attempt policy, markers and lack of a canned dialogue fallback are preserved. No preferred reply length is enforced.
- Generated conversational accounting is rejected as new stable characterization and excluded from old Dynamic Characteristic prompt projections. Concrete financial/military subjects retain legitimate views and habits, such as fair grain prices and inventory keeping; uncertainty favors retention. Unknown provenance and authored foundations are not reclassified. No campaign history, state, memory database or saved prompt is migrated, deleted or rewritten by this repair.
- Dynamic Characteristic selection requires relevance to the latest message instead of filling spare capacity with unrelated entries. It returns at most six entries, handles explicit hobbies/habit/earliest recall, and avoids treating incidental scene words as a memory request. High-confidence deduplication ignores word order and normalizes content tokens while retaining polarity, quantities and changed objects/places. Broader paraphrases can remain distinct; there is no semantic-model deduplication claim. New matching paraphrases retain a rejected record with their own lineage and leave the original active record intact.
- Category cues also retain childhood, values, aversion and aspiration recall when a question uses different words from the stored detail. The focused suite includes these cases and the existing Dynamic Characteristics contracts, so selective retrieval cannot silently remove those established self-details.
- Accepted physical gift language preserves `transfer_item` in the planner's bounded choices. No item name is hardcoded, and this only exposes a schema: normal planning, participant/item resolution, consent, authority and native execution remain mandatory. Currency transfers and atomic barter/ransom/diplomatic packages retain their existing routes.
