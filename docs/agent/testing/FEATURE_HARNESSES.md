## Feature harnesses

For Ruler Docket testing, every court-dependent profile first opens the production Court at the active safe capital through the shared visible `ui_open` route. This establishes capital-scoped royal access before any preflight, fixture preparation, hearing, or proclamation; pure post-advance, post-restart, and cleanup verification profiles remain session-neutral.

For noble semantic-acceptance tier two, treat natural promises to honor, obey, submit to, or accept the judgment, including a post-judgment acknowledgement that it is given or heard, as sincere reconciliation when the speaker also promises not to keep, renew, continue, or pursue the quarrel or declares that the quarrel ends here. Noble-hearing opening, ruler-question, and closing-reaction waits use the actual participant count: 120 seconds per expected speaker, each bounded from 120 through 480 seconds for the supported one-to-four active audience, within a separate 1800-second live-command timeout that contains all three sequential windows. Retain late-response and timeout evidence; never replace a slow production reply with canned text or credit a reply that arrived after the command verdict.
