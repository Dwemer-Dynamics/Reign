## Intended behavior

- Every supported route uses the same source identities, eligibility, question/answer links, correction history and character state: individual, group/party, social/event, tavern, court/official and correspondence.
- A character recalls what was said and by whom, including answers and later corrections. Disagreement and dissatisfaction remain possible after an answer.
- Every lasting life transition is retained as part of dynamic character: accepted commitments, roles, goals, relationships and personally relevant completed events. A concise current-state view influences conduct; original evidence explains how the character reached that state.
- Choosing to follow the player retains the actual agreed plan, reasons and conditions. It does not imply unconditional obedience, completed native recruitment, or knowledge for other characters.
- The writer retains 30 recent messages and 30 recent compact summaries. Older original exchanges remain searchable without sending an entire relationship archive.
- An extraction, tagging or action-validation failure cannot erase otherwise usable conversation. Withhold only unsupported updates/effects and record the actual outcome.

## Components and authority

| Component | Input and output | Authority |
|---|---|---|
| Identity linker | Native IDs, aliases, source speaker/audience, exact mention spans -> resolved or ambiguous identities | Never infer actor or recipient merely from participation/name presence. |
| Local extractor | Original exchange plus a bounded schema -> candidate entities, topics, event roles and relations | Suggestions retain offsets, model/schema version and confidence; no world actions or relationship numbers. |
| Source index | Verified source metadata and supported annotations -> rebuildable per-source search facets | Does not rewrite historical dialogue or summaries; invalidates on source/restore changes. |
| Retrieval specialist | Identity/topic/lexical/semantic candidates -> ranked original evidence bundles | Observer, timeline, save membership and as-of constraints remain mandatory; incomplete tags are not exclusion filters. |
| Continuity state | Original questions, answers, acknowledgments, corrections and plan revisions -> current conversation state | Preserve question ownership, independent concerns and explicit supersession. |
| Dynamic character | Accepted decision records and completed personal native events -> source-backed life transitions/current commitments | Distinguish event, stated intention, accepted commitment, execution and subjective meaning. |
| Dialogue writer | Character state and protected evidence -> visible prose and proposed updates | Owns voice and any visible rewrite; existing model selection remains independent. |
| Relationship/effect validators | Actual contribution, personality, established boundaries, accepted terms and native receipts -> bounded independent effects | Preserve legitimate reactions; no penalty for helper failure; action failure is contained. |

Use ordinary code for authoritative identities and rules. A separate model is not required for every component. Independent searches may overlap; extraction is cached and performed after acceptance/background where possible. No new remote model purpose or hidden checking call is introduced by the local path. Existing optional analyst/checker controls remain intact.

## Accuracy and performance gates

- Canonical roles: speaker/actor/subject/addressee/recipient/witness remain distinct; quoted and reported speech, ambiguous names, pronouns and kinship do not silently change identity.
- Search: paraphrased topics, old relationship history, multiple similarly named objects, letters and shared plans can discover the actual original evidence. Missing annotations do not hide otherwise eligible evidence.
- Temporal/privacy: no future, restored-out or unheard evidence; each group participant receives only their authorized projection. Receiving a letter differs from authoring or dispatching it.
- Continuity: question, actual answer, acknowledgment and correction reach the writer together when needed; an unsatisfying answer remains an answer. Source identity checks include actual content.
- Dynamic character: accepted plan/leadership persists across unrelated turns and save/load; conditions and objections survive; withdrawal/supersession is explicit. Marriage, loss and other completed life transitions remain distinct from inferred emotions and unexecuted intentions.
- Failure isolation: extractor unavailable/timeout/malformed/false positive and metadata rejection preserve accepted prose and unrelated valid effects. No repair-induced relationship reversal or hidden provider call.
- Retain exact drink-event, ownership, quantity, retry, handoff and persistence regressions and previously fixed text display/empty response behavior.
- Use the 53-exchange development baseline and existing audited cases; retain the independent 100-case human-label requirement. Label original evidence available at each turn, with no later-answer leakage. Require at least 98% required-evidence coverage and separately report answer coverage, attribution mistakes, false life-state promotions and downstream stored-update errors.
- Report local extraction/indexing/retrieval/prompt packing/generation/checking separately, including median/p95 and resource contention. Retain the 40% median total-input reduction target as unachieved until measured on comparable cases.
- GLiNER selection and any local reranker require actual semantic quality evidence; compilation, vendor claims and passing narrow fixtures do not establish qualification.
