    Chapter 01

    Requirements and resource use

    What you need before playing

    #

    Reign is a Windows PC single-player mod with a local companion server. You need a licensed Bannerlord installation compatible with your Reign package, its required native modules and installed dependencies, and the launcher's dedicated ReignServer WSL environment. Use a current supported 64-bit Windows installation with WSL 2 and virtualization available. Check the package's supported game version before updating Bannerlord; this guide is not a promise of compatibility with every future release or other mod.

    A cloud LLM provider is required for Reign's AI dialogue and generated character responses. Configure a supported provider/account and its credentials in the Control Center, with internet access and sufficient provider allowance or credit. The local Reign server manages the game connection, data, memory, and requests; it is not a replacement for the cloud language model. Some background rules run locally, but that does not make the full AI experience offline.

    A cloud image provider is also required if you enable optional AI-generated portraits or scene images. It is configured separately from dialogue. Working chat does not prove image generation is configured. Existing bundled or cached images can display without generating a new one; new image requests need the selected image route to be available. You can play with optional image generation disabled.

    Provider charges and subscription limits belong to the selected service. More conversations, longer exchanges, events, and new images can use more allowance. Never put an API key into NPC chat; save credentials only in the provider settings intended for them.

    RAM: plan for the game and the server together

    #

    Reign does not have a verified RAM minimum or typical-use range yet. Use the published base-game requirements below as base-game figures, leave room for the local Reign services, and assess memory pressure during your actual session. A single development session's allocated memory cannot establish a hardware requirement.

    ComponentWhat we can currently say
    Base Bannerlord, published requirementThe Steam listing gives 6 GB minimum and 8 GB recommended for the base game. These are system requirements, not measured process usage.
    Reign alongside the gameThe local server, database and memory worker need additional resources. Their ordinary and peak usage has not been measured well enough to publish a reliable extra-RAM figure.
    Your actual sessionCampaign age, battle size, settings, other mods and background applications affect memory use. Judge the complete session, including Reign's local services, rather than one process in isolation.

    We will add a typical-use range only after representative measurements during ordinary play, loading, saving and battles. Until then, the base game's figures are identified as base-game figures, and there is no separately certified Reign RAM requirement in this guide.

    If you check Task Manager, remember that committed memory is not the same as RAM currently resident in use. Do not count the Windows WSL process and Linux's own memory as two separate copies. If play stutters, inspect actual memory pressure and paging as well as CPU and graphics load.

    Processor, graphics, storage, and connection

    #
    RequirementPractical guidance
    CPUStart with hardware that comfortably runs your intended Bannerlord battles. The published recommended base-game CPUs are Core i5-9600K or Ryzen 5 3600X. Reign adds local simulation and services; no separate Reign minimum CPU has been benchmark-certified.
    GPU and VRAMMeet the game/DLC requirements for your chosen settings. The base-game listing recommends GTX 1060 3 GB or Radeon RX 580. Cloud AI generation does not require you to load a large language or image model onto your own GPU, but the game and native portrait rendering still use it.
    Game storageSteam lists 60 GB available for base Bannerlord. DLC and other mods can add to this.
    Reign storageKeep additional SSD space for the module, shipped portraits, dedicated server environment, database, generated images, saves, backups, and updates. Their size grows with use; a fixed small download size is not the full installed budget.
    Update and backup headroomKeep several tens of gigabytes free beyond the installed game as a planning allowance, then monitor actual growth. This is headroom advice, not a measured Reign install-size requirement. A full drive can interrupt saving, database work, or updates.
    InternetRequired while cloud dialogue or new cloud images are requested. Cloud latency, service outages, and provider limits affect response time even on a fast PC.
    Local servicesKeep the launcher-managed server, database, and memory worker healthy. WSL must have enough memory available; giving all system RAM to the game leaves no room for Reign's services.

    Base-game figures were checked against the official Steam system requirements on November 6, 2026. They do not include Reign or replace the requirements of any DLC you use. Reign-specific RAM measurements remain a follow-up; no new hardware requirement is inferred from a single development snapshot.

    How to use this guide

    #

    New to Reign? Read Your first session, then Your first conversation. After that, follow whatever interests you: ordinary adventuring, relationships, running a household, or ruling a kingdom. You do not need a crown to enjoy most social features.

    Use the contents to browse, the A–Z index to find a topic, or search in your own words: wife, have a baby, NPC won't leave, troops expensive, letters, save warning, or become senator. Search includes the whole manual, not just headings. Clear search to return to your place. Your browser's Find command also works.

    This guide describes effects rather than balance formulas. Where the game asks you to choose an amount, duration, price, or setting, read the current terms on screen. An example sentence is a suggestion for what to ask, never a guaranteed answer or a cheat code.

    Pictures marked In-game screenshot are actual captures supplied by a player. Click a picture to open it at full size. Pictures marked Layout example are temporary Reign design references with illustrative people, text, and values. Pictures marked Diagram explain a process. Text instructions describe current source behavior where an older reference differs.

    Edition note: This is a guide to the reviewed development checkout, including implemented previews. A Preview notice means native or final release acceptance remains open, or the installed edition may differ. It does not mean every part is broken. See What is still being verified for the main areas. This guide itself does not certify the mod's gameplay.

    What Reign changes

    #

    Reign adds a remembered social and political world to Bannerlord. NPCs have personalities, interests, relationships, private concerns, and different knowledge. Conversations can lead to genuine agreements and game actions. Letters travel, stories continue, families develop, councils deliberate, and rulers face consequences.

    It also changes things outside chat: the calendar is longer, exact NPC relationship scores are hidden, recruitment draws on village population, advanced troops are more expensive, raids leave lasting damage, garrisons and field armies have different burdens, and important world events reach you as news. Arena Overhaul is bundled into the Reign module.

    You still play Bannerlord. A description of a gift does not create an item, a boast does not win a battle, and council advice does not automatically issue an order. Real effects depend on the actual people, resources, authority, and game situation.

    Your first session

    #
    1. Use the installed Reign launcher and its managed server controls. Start the local server and open the Control Center. Check its health before loading a campaign.
    2. In the Bannerlord launcher, enable ReignBeta and the required installed dependencies: Harmony, ButterLib, UIExtenderEx, and Mod Configuration Menu, alongside the required native modules. Use the dependency ordering shown by your installed package. Arena Overhaul belongs to Reign's module; avoid enabling a second standalone copy alongside it.
    3. In the Control Center, confirm your selected dialogue provider is configured. Configure image generation separately if you want it. A local server does not by itself make cloud AI requests free or offline.
    4. Load your campaign. Let Reign finish its preparation screen. If a stage fails, use Retry; the preparation records completed work.
    5. Approach an available adult NPC and have a short conversation. Press backslash (\) or use MCM → Utilities → Open Party Chat if you want a group conversation. Ctrl+M opens Correspondence from a suitable campaign-map screen.
    6. Save with the server running. Pay attention to any Save Sync warning. Keep a matching campaign backup and native save before major changes.

    The current launcher-facing local address is http://127.0.0.1:8089. Keep the URL selected by your installation; older instructions referring to a standalone Windows server or a different port may be out of date. The server now runs in its dedicated ReignServer WSL environment, managed by the launcher. Ordinary players do not need to run development commands.

    The preparation process connects the native save with Reign's matching history, prepares characters and households, and restores ongoing systems. New campaigns have an opening grace period before the autonomous world becomes busy. An initially quiet world does not mean the mod has failed.

    Chapter 03

    Your first conversation

    Approach, speak, and listen

    #

    Open an eligible person's Reign conversation. With NPC Lives enabled, Approach can begin with what they are doing and how receptive they are. Speak naturally and be specific. “Could you tell me about your work?” is a useful first question. You can ask about their interests, recent events they might know, your relationship, or a practical request.

    Use Enter or Numpad Enter to send a ready message. Alt+A opens the action builder when this conversation has an eligible participant and is not busy. Escape first backs out of a supported open image or outfit layer, or closes the conversation when no protected decision is in the way. A pregnancy choice has its own controls; do not assume Escape answers it.

    NPCs can refuse, negotiate, misunderstand, conceal something, or ask for clarification. Their rank, duties, personality, relationship with you, and the people present matter. An adult civilian and a reigning monarch do not have the same authority.

    Reopening a recent conversation can restore it silently instead of producing another greeting. An unfinished reply may still be running; reopening is not a reason to send the same request again. If you see a clear failure with a retry control, use that control and inspect the result.

    Look for the writing area, the person you are addressing, and any action or pending-agreement controls. The current screen also has Look at them and View features described under Pictures and appearance.

    Asking for a real action

    #

    For an explicit mechanical request, press Alt+A in a supported, ready Reign conversation to open the action selector. Its builder starts with I would like you… for the other person to act or I wish to… for your own offer. Choose the person, action, target, and requested terms. Review the resulting sentence before sending it with your speech.

    Inside the builder, Enter advances a text-entry step or accepts the completed action when its accept control is ready. Escape cancels the builder and returns to chat. Inserting the sentence does not send it: use the chat's Send button, Enter, or Numpad Enter after reviewing the full message. Alt+A is unavailable while the conversation is busy or has no eligible action participant.

    The available choices depend on the person and situation. You may see Give…, Go to…, Support…, Government decisions…, Court and intelligence…, Party and military orders…, Diplomacy…, Clan and kingdom…, or Personal requests…. Search inside the builder if you know what you want.

    The attached action sentence is kept as one meaningful unit. Editing the surrounding speech is different from changing the action's terms. If you change the agreement, review the new version and obtain fresh acceptance. A counteroffer is a new set of terms, not acceptance of the earlier offer.

    In the focused message editor, Ctrl+A selects all, Ctrl+C copies, Ctrl+X cuts, and Ctrl+V pastes. Backspace/Delete remove selected text; their Ctrl variants delete by word. An attached action keeps its protected boundaries. Copying ordinary sentence text does not supply fresh agreement—use Alt+A to build the actual action again where needed.

    Try this: offer a small, affordable gift to a willing person using I wish to… → Give…. Name the actual item or gold amount. Check your inventory or money afterward. This teaches the difference between discussing a gift and completing one.

    Agreement is the beginning, not the result

    #

    After a request, distinguish three things: what you asked, what the NPC accepted, and what actually happened. A journey can be accepted but still take time. A transfer can be blocked by ownership, missing funds, distance, captivity, a changed target, or another active duty. An unsupported request cannot become real merely because the reply sounds enthusiastic.

    Check the action status and the native result: did the gold move, did the item change hands, did the party leave, did the treaty appear? A failure message is useful information. Correct the stated problem before trying again; repeatedly asking does not grant authority or multiply resources.

    Ordinary roleplay can still matter to relationships and memories. Treating someone kindly, insulting them, making a serious promise, or betraying trust can have social consequences even when no inventory transfer occurs.

    Terms, conditions, and ongoing agreements

    #

    The action builder (Alt+A) can describe supported future timing, conditions, repeated payments, and exchanges with more than one term. Read who acts first, what triggers the next step, and what is still owed. “Give me this now and I will pay later” is different from an immediate exchange.

    Only the agreed revision binds the participants. Countering an amount, recipient, location, or date needs fresh acceptance. A pending, waiting, failed, cancelled, or recovery-required agreement is not completed work. Use its supported revise or cancel route and inspect any terms already fulfilled; cancellation does not imply that history or a real transfer is undone.

    Do not assume every conceivable condition is supported. The builder's actual choices and validation determine what the installed edition can do.

    What you can ask people to do

    #

    Supported action families include giving or trading gold, possessions, equipped gear, troops, prisoners, workshops, land, and ships where applicable; following, guiding, traveling, waiting, and patrolling; party and army orders; mercenary service, clan or kingdom membership; court and intelligence work; diplomacy; political support; meetings; and personal experiences.

    Each has its own restrictions. Someone cannot give away another person's workshop, command an army they do not lead, or promise a government's vote on everyone else's behalf. A ruler's request and a peer's request are different. Ask the actual decision-maker and keep the purpose and terms clear.

    If a guide agrees to Show the way, follow them in the scene. Their agreement does not teleport you to the destination. If you leave them behind, the task can remain waiting or require recovery.

    Chapter 04

    Action sentence system

    Build and send an action sentence

    #

    Open a supported Reign conversation with an eligible adult and press Alt+A once it is ready. Individual Chat, Party Chat, Correspondence, social events, the tavern house, supported court audiences, Royal Council, and a selected War Council messenger can host the builder. Select the actual participant. In Correspondence, Ctrl+M opens the inbox from the campaign map.

    1. Choose I would like you… to ask the other person to act, or I wish to… to offer or declare an action of your own.
    2. Choose the action, then fill in the people, destination, quantity, or other terms. Use the builder's search for a named action or target.
    3. Review the sentence. Use Back to change a choice. Enter advances an entry or accepts a ready draft, and Escape closes the builder.
    4. Accept inserts the protected sentence in your message. Review any ordinary speech around it and then use the host's Send control. In Individual Chat, Party Chat, and Correspondence, Enter or Numpad Enter also sends a ready message.
    5. Read the answer and check the outcome. An offer may be refused or countered. A counteroffer changes the terms and needs fresh approval. Look for the actual transfer, arrival, report, or other effect.

    The lists below group actions by purpose. They include menu choices, offers that arrive through events, and follow-up controls. A choice can depend on the opening direction, eligible people and assets, current duties, location, authority, and feature settings. The chosen conversation may have further restrictions. Each row explains the situation and the choices or result. Some names in search may vary with the direction of the sentence.

    Use Review offer from… when an NPC has made an actionable offer. Inspect its exact terms before accepting or choosing Decline this offer. To counter, change the term in review and send the revised sentence. To stop a running order, use its cancellation route. The protected sentence is one attached action. Reopen it through Alt+A to edit the draft, or remove it as a unit. Plain copied text carries no attached terms. Once focus returns to chat, pressing Enter can send the message.

    If a choice is missing, check who acts, whom you addressed, whether they are free to act, and whether the feature and target are available. Some offers appear only when an event raises them. Try the exact action name in the builder's search.

    Bargains and timing

    #

    A gift or request can end after one complete term. To negotiate an exchange, choose and I will give… or and you will give… in review. Add another action… combines compatible actions, and Edit a term or its timing… changes a selected term. A marriage proposal limits the consideration to the supported marriage assets.

    Where the term allows it, choose execution as soon as delivery and the bargain allow, after a number of days, on arrival at a settlement, on release of a prisoner, on ownership of a settlement, or on peace or war with a named realm. Installments repeat the displayed amount at the chosen interval. Read the total before agreeing. Payment can be made in advance or after verified fulfillment where the builder offers that choice.

    Remote terms can take time to deliver. Authority, stock, funds, and world state are checked before execution. Rebellion declarations and public pregnancy disclosures have their own immediate player declaration flow. For a negotiated action, check both consent and fulfillment.

    Gifts and exchanges

    #

    Open Give… or use a give option in bargain review. The person supplying the term must own or lawfully control the selected asset. These actions can be gifts or pieces of a larger exchange.

    ActionWhen and how to use it
    Give goldChoose the payer, recipient, and amount. The payer must be able to fund the transfer.
    Give an itemChoose the owned item, exact variant or eligible equipment slot, and quantity where applicable.
    Give troopsChoose the troop type and number from an eligible roster. Check the parties and their available troops.
    Give prisonersSelect captives in the giver's lawful custody. This hands them to the recipient.
    Give landSelect an eligible town or castle the giver can lawfully transfer. The transaction changes its ownership.
    Give a workshopSelect a workshop owned by the giver. The recipient must qualify to take it over.
    Give a shipSelect an eligible owned ship in a campaign that supports ships. Check transfer restrictions and location.

    Personal and family actions

    #

    Use an eligible conversation with the people concerned. An NPC's personal offer can surface through its own interaction, with a review step for the agreed terms.

    ActionWhen and how to use it
    Leave your spouse by letterUnder I would like you…, ask a married adult NPC to send their current spouse a private separation notice. If agreed, it ends that marriage and can badly damage relations with the spouse's clan. The letter is the notice produced by the action.
    Expose their concealed pregnancyUse I wish to… as the only action in the draft when your character has the required verified knowledge. Choose the confirmed case and whether to name the known father.
    Share this personal experienceReview an NPC's current personal-story offer when that event presents it. Acceptance applies to that specific offer.
    Take personal leaveWhen the NPC offers personal leave, review their proposed departure and time away before agreeing.
    Summon a subordinate for a meetingAsk a qualifying clan leader or ruler to summon their subordinate. Select the person, place, reason, and stay. Review the quoted arrival and any army release.
    Change an agreed meetingIn a conversation eligible to control the live meeting, select it and agree to the new place and duration. The arrival time is recalculated.
    Cancel an agreed meetingChoose the current meeting and agree to cancel. Reign releases the movement commitments made for that meeting.
    Join my party as a permanent companionAsk an eligible known resident. Agree the exact payment, if any, and check companion capacity. Soldiers need duty release first.
    Release resident from dutyAsk the eligible commander or home-owning clan leader to release the named military resident before recruitment.
    Join my party as a temporary guestAgree in person with an eligible foreign noble or known resident. Set the purpose, fixed or open-ended stay, and any payment or army exit terms shown.
    Extend your stay in my partyAsk a live guest who is still in your main party. Agree the revised term and relevant payment.
    Leave my partyEnd the specific live guest agreement. The noble begins the return to their home party or other eligible destination.
    Accept the risks of fighting your own factionAsk a current guest under I would like you… when they face this risk. Fighting their own faction can replace them in their old role, banish them, and move them into your clan.

    Marriage actions and wedding choices

    #

    Open the exact offer through View marriage offer or address the issuing clan leader through Alt+A. The dedicated wedding choices appear only with a relevant offer or ceremony. See Arranged marriage offers and cultural weddings for the delivery window, town visit, and settlement sequence.

    ActionWhen and how to use it
    Propose an arranged marriageChoose an eligible leader, select your clan's prospect and theirs, and review the exact consideration before sending.
    Release a captiveIn marriage bargain review, select a captive held by the side providing that term. The person goes free when the marriage settles.
    Ask the prospective spouse to call off the weddingDuring the exact active ceremony, ask an eligible prospective spouse directly. The decision belongs to that person.
    Marriage allianceUse the marriage action with the exact eligible consenting couple. In personal conversation this binds the actual participants. Clan offers for relatives use the dedicated proposal route.

    For an incoming offer choose Accept this marriage proposal, Refuse this marriage proposal, or Request a meeting with… when offered. Select a safe town for the meeting and confirm the response to the issuing leader. Once the agreement is ready to book, the applicable choice is Marry now or Hold a ceremony. The ceremony also offers Withdraw from my wedding… for a participating player who chooses to end it.

    Arrests and direct conflict

    #

    Address the accused for the arrest actions. Choose I wish to… to prepare an arrest, release a person, or rescind the case. A prepared arrest can lead to explicit confirmation, surrender, a duel, or a fight. See Arrests, confirmation, and custody.

    ActionWhen and how to use it
    Duel meAsk the current NPC to duel. Select the available duel mode and play out the fight.
    Prepare arrestUse I wish to… with the accused present. Enter the accusation, category, and severity. Confirm through the next arrest step.
    Release arrested characterAs the player, select an applicable arrest case in custody. Release the person while leaving the accusation on record.
    Rescind arrest accusationAs the player, select the case to withdraw. Custody ends if that case is what holds the person.
    Attack your partyUse I wish to… after the accused refuses surrender in the prepared arrest. Select the case and eligible current party.
    Attack my partyAsk a party leader to attack the player's party where the game permits the conflict.
    Surrender to meAsk the current NPC to surrender their eligible party. Resolve any subsequent custody or surrender step in the game.
    Leave me aloneAsk the actor to stop pursuing or threatening your party. This affects the current behavior.
    Kill characterChoose the living character targeted by the execution and review who will carry it out. The game excludes the player character and can block execution through campaign protections.

    Following and guiding

    #

    These requests use the available scene or campaign context. A guide leads the way in the world and waits for observed arrival.

    ActionWhen and how to use it
    FollowAsk an eligible actor to follow a person present in the scene or to follow the specified party on the campaign map.
    Stop followingAsk the actor to end their current scene follow or campaign escort.
    Show the waySelect a present person or recognized passage. Walk with the guide and allow them to register your arrival.

    Party and military orders

    #

    Use Party and military orders… with the eligible commander, including via the War Council's messenger or a supported conversation. An order is supervised over campaign time. Check the chosen objective, targets, food, troops, army authority, and safe route. These orders command eligible NPC parties. Your main party can be an escort target, while you retain control of its movement. Identical objectives with alternate labels share a row. Attack settlement and Capture settlement plan have their own choices.

    ActionWhen and how to use it
    Issue campaign orderBuild a supervised order with a single objective or combine stages. Set each stage's target and requirements, then confirm with the commander.
    Revise campaign orderChoose the active order and agree the new objective, destination, area, or timing. The same order keeps its history.
    Cancel campaign orderChoose the active order and agree to stop it. Its previous accomplishments remain recorded.
    Create partyAsk an eligible lord without a party to establish one. Creation still depends on authority, local troops and funding.

    Chapter 05

    Getting to know people

    Personalities, interests, and private concerns

    #

    Characters have lasting personalities rather than a fresh personality each time you open chat. They can have hobbies, hopes, fears, values, attachments, a public manner, and private concerns. Compassion, honor, loyalty, responsibility, courage, judgment, and social boldness help shape their choices. Boldness in conversation does not necessarily mean courage in battle.

    Newer campaigns use richer authored backgrounds and stronger individual interests. Older campaigns retain their established profiles instead of silently replacing everyone's life story. Interests give you subjects to explore; they do not guarantee that every conversation will return to the same hobby or that an interest grants a mechanical skill.

    Personality can develop through meaningful experiences over time. Repeating the same compliment in one sitting is not a reliable way to rewrite someone's beliefs.

    What NPCs know, believe, and keep secret

    #

    Reign separates actual world events from what each person has learned. A participant may know a battle immediately, while a distant court hears about it later. A private conversation is not automatically public. Someone may know your name or deeds without recognizing your face.

    An NPC can repeat a mistaken report or deliberately lie. You can ask who told them, challenge a claim, or provide evidence. Persuasive speech can affect belief without changing what really happened. Conflicting accounts are not automatically a continuity bug.

    Memory follows participants and context. People can recall shared conversation, commitments, important events, and experiences. They should not inherit the private contents of an unrelated person's conversation simply because they live in the same town.

    Relationships, visible status, and skills

    #

    Relationships are directional: you may like a person more than they like you. Time together, compatible personalities, conversation, shared obligations, and major actions can change that relationship. A lasting favor or betrayal can matter beyond one exchange.

    Reign hides exact NPC relationship scores throughout much of Bannerlord's interface. Read behavior, known history, and social clues rather than treating everyone as a visible score. Reveal All Character Relationships in MCM is an optional cheat. Skills remain visible in their normal mechanical interfaces.

    Clothing, equipment, holdings, reputation, and visible position affect how others perceive you. NPCs do not automatically know the exact amount in your purse. Dressing like a courtier and possessing a courtier's actual power are different things.

    Added nobles and wanderers

    #

    Reign adds landless noble households to deepen local courts and expands the world of persistent characters. A landless court household is not automatically a field army; acquiring land can change its opportunities. Younger family members, local residents, and wandering adults serve different roles.

    Wanderers have individual identities and culture-appropriate backgrounds. Recruitment and companion limits still matter. Once someone is a persistent Reign character, their established identity and conversation history should not be treated as a disposable tavern extra.

    Eligible notables and encountered residents can use supported recruitment routes too. A recruited notable's former service and workshop dialogue need to follow their real current status; a former job does not grant you ownership of the town's business. Use an actual workshop-transfer agreement for a change of ownership.

    With War Sails, the Nord towns and castles have 13 additional tier-one court households and 78 authored nobles, with family ties, biographies, and shared portraits. Start a new campaign to meet these households. Their clans can gain rank normally. The content is installed and broader new-campaign acceptance is still open.

    Party Chat and private audiences

    Preview included#

Eligible people depend on your party and safe location; availability is not permission to speak to someone across the world.

Supported private or whisper conversations have a narrower audience than the whole group. Check the selected recipients before sharing something sensitive; merely being listed in a directory should not make someone a participant in a private Homes conversation.

    Changing a group can create a different conversation context. Where Continue is available, it resumes a retained group only when the original members and location are still eligible. A remembered transcript is not proof that an absent person has returned.

    Preview included#

    Named adults actually traveling in your main party may talk among themselves in a small map window. Waiting in place does not start travel banter. Prisoners are not conversational party members for this feature.

    You can move the window by its title bar, resize it with the corner grip, and minimize it. Its dialogue control lets you join the selected speakers in Party Chat. Joining continues the exchange instead of asking the AI to invent a second opening. If the original speakers are unavailable, an old transcript may remain readable without becoming a live conversation.

    Window position and size are local interface preferences. They are separate from your campaign's memories and relationships.

    Correspondence: sending and receiving letters

    Preview included#

    Press Ctrl+M from a suitable campaign-map screen, or use MCM → Utilities → Open Correspondence. Choose a known living contact, read the thread, and write your message. Enter or Numpad Enter sends a ready letter; Escape closes the screen. Alt+A opens the action builder for an eligible selected correspondent when it is not busy.

The list can also surface commanders who send order reports. A sent letter first travels, then arrives, then can be marked read. A reply has its own journey.

    Letters are faster in the revised system than in older editions, but they are not instant long-distance chat. Nearby letters arrive sooner than distant ones. Delivery-time and unsolicited-letter frequency adjustments live in the Control Center's Options. Changes affect future dispatches rather than rewriting a letter already in transit.

    Characters can write first, including an eligible introduction. You do not have to start every relationship by finding its owner in a keep. An introduction is delivered before the new correspondent becomes an ordinary contact. As your reputation grows, people from other houses may reach out and invite you to become acquainted.     If a reply seems late, check whether the outgoing letter has arrived and allow campaign time to pass. Repeatedly sending the same question creates more correspondence, not a faster courier.

    An arranged marriage proposal can arrive as a signed letter. Open View marriage offer on the sender's thread to inspect or respond. See Arranged marriage offers and cultural weddings for the choices and deadline.

    Promises to inform someone or send for them

    Preview included#

    Preview: source-backed message commitments and summoned meetings have substantial implementation and partial native evidence, with further acceptance open.

    An NPC's clear promise to inform another named person can become a real message. While the conversation is still open, the promise can be corrected or withdrawn. Explicitly closing the conversation releases accepted outgoing commitments; a temporary screen handoff is not the same as finishing the talk.

    The recipient learns the delivered message, not everything you privately discussed. Asking an NPC to pass on an offer does not make the recipient accept it. A question needs a real answer and return delivery. A summons is an invitation that can be refused; acceptance still needs a safe location, travel, and an agreed stay.

    For a direct subordinate meeting, state the person, place, purpose, and length of stay. Keep the distinction between waiting for arrival and time spent together after arrival. A promised arrival is not evidence that the NPC is already present.

    Chapter 07

    Events and NPC personal lives

    Town events and tournament celebrations

    Preview included#

    When a social event is announced, visit the named town and use Attend the announced Bannerlord Reign social event. If you leave an active event, its Return option can reopen it while available. These are opportunities with closing windows; an announcement is not a permanent quest marker.

    Culture shapes the gathering. You may encounter feasts, fairs, dances, performances, contests, or outings. Events proceed through phases, giving different opportunities for introductions, group conversation, competition, or quieter exchanges. Tournament celebrations connect the local social scene with the winner and prize.

    Participation can develop relationships and award modest player skill experience. A real exchange matters; repeatedly opening a screen does not count as participation. See Participation XP for its settings.

    Wilderness encounters and personal matters

    Preview included#

    While traveling outside settlements, you may encounter a contextual scene involving eligible party heroes. Terrain, time, and companions affect its presentation. You can investigate, talk, apologize, challenge, avoid the issue, or end the exchange according to the situation.

    These scenes can also bring a developing rivalry, romance, shared secret, or obligation into the open. A private concern is different from a public court matter. Events do not need to occur during every journey, and the game avoids opening them over battles, sieges, or other unsafe interfaces.

    Approach, invitations, and personal stories

    Preview included#

    Preview: NPC Lives has implemented stories and partial native tests. Meeting travel, leave/return, some mission outcomes, and final acceptance remain in progress.

    With NPC Lives enabled, people have activities and may be busy, relaxed, worried, or ready to ask for help. Companions and eligible guests actually accompanying you can invite you into personal experiences. Being in the same kingdom is not enough to receive every private invitation.

    Brief moments, outings, personal leave, independent activities, and longer story arcs have different purposes. Trust affects what someone is willing to share. Follow the stated objective, the agreed people, and any revealed Story Location in the relevant settlement. Meaningful conversation and actual activities move a story forward; repeating a password or praise does not guarantee progress.

    Some stories involve a practice duel, a hideout, an item, or travel. Those require the real game outcome. A story describing success cannot grant a victory, a reward, or a completed mission by itself. Lasting experiences, belongings, pets, and character development are intended to remain part of later conversation when actually established.

    Personal leave and changing plans

    Preview included#

    An NPC asking for leave may have a private reason. You can discuss it, ask them to wait, or negotiate the arrangement. Repeating the same argument does not create unlimited persuasion credit. They can remain unwilling to disclose a concern or accept your request.

    Agree separately on any delay before departure and the time away after departure. Accepting time away does not permanently dismiss the character or recruit a replacement. Native return and duty restoration belong to the agreement's lifecycle, so inspect its status if the person seems overdue.

    Turning off new NPC Lives invitations stops new starts; existing commitments and safe recovery may still need to finish. It does not erase memories or make an accepted journey vanish.

    Attention, jealousy, invitations, and rescues

    Preview included#

    People can notice you giving attention to others without overhearing the private contents. Neglected acquaintances may ask to talk; their temperament and what they actually witnessed affect the complaint. An approach is not proof of romance or wrongdoing.

    You may also receive invitations from local nobles, friendly patrol interceptions, or a chance to speak after a battle or prison rescue. These use the actual people and circumstances. Rescue conversation is separate from the native release or reward.

    Options → Player attention and NPC approaches has a master switch and separate preferences for attention, jealousy/neglect, keep invitations, patrol interceptions, and battle or prison rescue dialogue. Turning them off changes new approaches rather than undoing completed rescues.

    People you meet can become persistent

    Preview included#

    Beginning an explicit Reign conversation with an eligible peaceful adult civilian, guard, or soldier can make that exact person a persistent character.     The same person can be recognized later instead of being replaced with a generic extra. Their hometown and earlier life remain relevant after recruitment. A narrative family is not automatically a set of native Hero relatives; ask naturally rather than assuming empty native family links mean they have no household.

    To recruit a resident, ask for voluntary agreement and review any price, companion capacity, and duty-release conditions. A soldier leaving service needs lawful release and real manpower accounting. Permanent recruitment is different from inviting a temporary visitor.

    Preview included#

    Preview: the town tavern venue is implemented and deployed in its recorded edition; full native acceptance remains open.

    In a town's tavern submenu, Visit the Madam opens a staffed venue with a madam, worker cards, conversation, and optional scenes. Adults have persistent identities; they are not newly invented for each visit.

    Discuss the people and payment with the madam, then review the exact participant and price confirmation. Only the confirmed participants join the private visit. Choosing a card or discussing a price is not payment. Campaign time stays paused until you leave the visit.

A quiet period can let an active rumor subside; an established reputation is harder to lose. Staff can be recruited only through voluntary, supported agreement, and the venue replaces departed or retired workers with distinct people.

    Clothing, drinking, and firm refusals

    Preview included#

    Characters can change outfits through a supported conversation request. A preview lets you compare the old and proposed appearance before keeping or reverting a change. Equipment, ownership, and eligible clothing still matter. Mounts and horse equipment are not wearable clothing props.

    Narrated drinking can build a persistent level of intoxication through an actual shared activity. A mention of a drink is different from a completed drink. Intoxication can affect how someone speaks and later recovers; it should not reset simply because you close the chat.

    NPCs can maintain firm refusals and negotiate for their own reasons. A prior gift does not purchase universal consent. A serious new reason or different terms can be relevant, but endless repetition is not a guaranteed way around a refusal.

    Chapter 09

    Relationships and starting a family

    Friendship, romance, and long memories

    #

    You can build affection through shared time, conversation, help, and compatible interests. Background relationship processing can also bring people closer or create friction. One person may feel more strongly than the other.

    Romance can progress from flirtation to a closer and more serious bond. Same-sex romance is supported. Rivalries, favor debts, marital conflict, and shared secrets can become ongoing stories rather than temporary mood changes. A life-changing act carries more weight than a routine compliment, especially when the benefit actually reached the recipient.

    Affairs and flings depend on the people involved and can lead to jealousy, rumors, pregnancy, estrangement, and public consequences. One willing person cannot supply the other's agreement. A marriage can deteriorate or end; its consequences can extend beyond the couple.

    Marriage and NPC matchmaking

    #

    Native player courtship remains available. Use the arranged marriage flow to negotiate a named couple through their clan leaders. A match and its final marriage can happen at different times.

    With Use Reign-Controlled NPC Marriage enabled in Reign's MCM, background matchmaking favors clans of comparable standing. A lower-standing clan may need to pay compensation. Royal matches with landless houses require a rare opportunity as well as approval and funding. A completed match can improve both leaders' relations. A formal refusal can damage the proposer's view of the other leader, and identical refused terms are remembered. Changing the matchmaking setting preserves existing marriages.

    Leave your spouse by letter asks an eligible married NPC to end their existing marriage. The NPC must consent to the exact terms. Separation takes effect with a private notice and can badly damage relations with the former spouse's clan. A later marriage needs its own agreement.

    Arranged marriage offers and cultural weddings

    #

    A clan leader can propose a match for you or an eligible member of your clan. To start a proposal, open Alt+A with the eligible clan leader and select Propose an arranged marriage…. Confirm both names, which clan a spouse would join, and the agreed gold, items, captive release or transfer, and eligible land. The exact accepted terms carry forward to settlement.

    1. Open Correspondence with Ctrl+M. Select the issuing leader, then choose View marriage offer. You can also use the action builder with that leader in an eligible conversation.
    2. Choose Accept this marriage proposal, Refuse this marriage proposal, or Request a meeting with… when available. You have 30 campaign days from delivery to respond.     3. For a meeting, choose an eligible town and check the arrival estimate before sending the request. There is one timed visit for the offer. Speak privately with the prospective spouse to learn their answer.

    Having a baby: the important change

    #

    A new player-parented pregnancy can begin only through a qualifying intimate event in an individual Reign conversation. Bannerlord's background spouse-visit pregnancy system is disabled for the player and their spouse. Simply marrying, waiting together, traveling with your spouse, or sharing a settlement will not create a new child parented by the player.

    This applies whether the player would be the mother or the father. A group conversation, a letter, or an announcement is not the individual-chat conception route. The relationship, adult eligibility, reproductive age, biological pairing, and family restrictions still apply. A qualifying scene creates an opportunity, not a guaranteed pregnancy.

    When the qualifying scene reaches its reproductive choice, read the actual inquiry. Proceed allows the conception opportunity to resolve. Pull Out prevents that opportunity and returns the choice to the conversation. Reopening or repeating a cancelled choice does not create another roll for the same event.

    Pregnancy, parentage, and pregnant companions

    #

    Reign distinguishes biological and legal parentage. A pregnancy can be private, and revealed illegitimate parentage can bring social consequences. A child's recorded history is not just whatever someone last claimed in dialogue.

    The action selector can also expose a confirmed concealed illicit pregnancy when the required knowledge exists, with optional known paternity. That is a public disclosure with consequences, not a guess based on a rumor or an omniscient way to discover a secret.

    With Restrict Pregnant NPCs From Combat enabled, pregnant NPCs withdraw from field duties and cannot start normal combat or military orders. They seek a safe fortification; party command may transfer or the party may be handled safely. This setting excludes the player character.

    Birth restores ordinary eligibility, but it does not magically recreate an old party. Switching the setting off likewise does not reconstruct a party that was already disbanded. If your pregnant companion is unavailable for a patrol or duel, check this setting before treating it as a broken order.

    Children and Family Chambers

    #

    Use Family Chambers from Royal Court or Explore the keep → Castle Layout to find eligible adults and children present in that household. Adult cards and child cards are connected: selecting a parent helps you find their children, and selecting a child helps identify available parents.

    Use Escape to return from the Family Chambers screen. It is a screen-navigation key, not a decision about the family.

    Children receive age-appropriate family conversation, not adult romance or military orders. They can remember childhood interaction, with very early memories treated differently as they grow up. Education and normal skill information remain visible in the appropriate native interfaces.

    Chapter 10

    Gossip, reputation, and Public Standing

    Gossip is not proof

    Preview included#

    Personal gossip is information moving between people. It can be delayed, private, mistaken, selectively repeated, or maliciously exaggerated. A speaker needs a reason to know something; the entire map does not instantly hear every private incident.

    Rumors are temporary public suspicions. Repeated or decisive evidence can establish a longer-lasting reputation. A correction can disprove an active rumor without instantly erasing what society already regards as settled. Neither a fabricated rumor nor a forceful accusation rewrites the actual event history.

    Preview: the expanded personal-gossip and delivered-message systems have continuing acceptance work. Their privacy and travel rules matter when interpreting what an NPC should know.

    What your reputation changes

    Preview included#

    Public Standing reflects how active rumors and reputations shape your social position. It affects existing social connections rather than making every stranger a close acquaintance. Charm can soften negative reactions; it does not undo the underlying conduct.

    The same event can have personal and public consequences. A spouse's reaction to an affair is not the same as a distant courtier's. Favoring one courtier can create jealousy in others. Public judgment is also shaped by the setting's unequal social norms, including different treatment of some men and women.

    Preview included#

    First identify whether the problem is a rumor, an established reputation, a personal relationship, or a real unresolved act. They need different remedies. Correct false information, fulfill promises, address the cause, or use a Spymaster's supported social mission. Removing gossip does not release a prisoner or repair a betrayed relationship by itself.

    Chapter 12

    Ruling a kingdom

    Capitals and Rule Mode

    Preview included#

    As ruler, use Designate Capital in an eligible town of your kingdom. At a safe kingdom town or castle, Enter Rule Mode opens court business. The capital provides Royal Court with full royal scope; another eligible holding provides a reduced Local Docket. Captivity, siege, and unsafe conditions can interrupt access.

    Enable Court System in MCM if the menu is unavailable. A saved setting that turned it off stays off after an update. Owning a castle without ruling a kingdom does not automatically grant full royal authority.

    The Royal Court's main areas include Court, Court History, Lands, Subjects, Diplomacy, Ambassadors, Spymaster, and Military, with entrances to Government, Royal Council, Family Chambers, and Castle Layout. Use Lands and the Economic Report to investigate a shortage before deciding how to spend the treasury.

    Escape closes the main Court screen. In a supported conversation opened from court, Alt+A opens actions; it is not a shortcut for every Court tab.

    The Court window fits itself to your display while keeping its proportions. Recent development work corrects its size on taller displays; check the installed version if yours looks different.

    Hearing and deciding petitions

    Preview included#

    Petitions come from actual needs rather than a queue filled with invented emergencies. Core petitions concern food, town funds, village recovery, and soldiers for security. Read the petitioner, settlement, requested aid, and proposed commitment.

    Talk with the petitioner, then use the explicit decision: grant direct aid, fund a supported alternative, or refuse. Conversational sympathy alone does not spend the treasury or send soldiers. If you lack the resources, a pending case does not count as fulfilled.

    Direct soldier aid detaches real troops while protecting a minimum home defence. An expedition can suffer losses and returns through its recorded route or a safe fallback. Gold alternatives can be costly because they fund the replacement work, not merely the face value of a few items. Petitions do not simply vanish because you postponed them.

    Try this: open a food petition, inspect the affected holding, and compare direct aid with the funded alternative before deciding. Check Court History afterward for the recorded result.

    This audience concerns an envoy's offer to fund a friendship ceremony. Talking through an offer and confirming a decision are separate steps; read the final terms before confirming.

    Noble disputes, visitors, and patronage

    Preview included#

    Preview: broader noble, international, household, visitor, and patronage business exists in the court implementation; it is separate from the certified core relief-petition slice and has further acceptance work.

    Court life also includes noble disagreements over precedence, insult, scandal, family affairs, property, and more serious misconduct. Hear each actual principal, consider the known evidence, and read the available ruling. A losing side can accept, resent, or resist your judgment. An accusation does not automatically establish the accused behavior or its reputation.

    Foreign court matters use the relevant international participants and authority. A local household quarrel is not permission to commit another kingdom to a treaty. Native marriage, custody, imprisonment, or death still needs its actual supported game action; conversation cannot bypass it.

    Noble visitors can make courtesy calls, introduce themselves, or bring family introductions. A reserved visit can temporarily make someone unavailable for an office or other duty. A social introduction is not an accepted marriage.

    Patronage brings artists and supported commissions into court life. Review the named work, price, and delivery before funding it. Discussion alone does not grant a commissioned work or its benefits; only a properly paid supported commission does. Some audiences provide characterization without a mechanical reward.

    Chancellor and delegation

    Preview included#

    Ask an eligible person in direct conversation to become Chancellor, agree on pay, and review the appointment. The Chancellor is a capital-resident docket office, separate from the Royal Council seats. It may require leaving an incompatible governorship or field command.

    Appointment begins inactive. Activation and deactivation take effect at the next scheduled morning docket boundary, rather than immediately rewriting the day. Active service costs its agreed daily salary and suppresses ordinary petitions. Unpaid service cannot continue indefinitely.

    Delegating often can give you the social appearance of an absent ruler. Captivity has an emergency Chancellor lifecycle and a handoff after release. The old Regent is retired; historical Regent entries do not mean that office still governs your current court.

    Offices and the Royal Council

    Preview included#

    Court work depends on capable, loyal, trustworthy people as well as skill. Steward, Economic Advisor, Foreign Advisor, Marshal, and Spymaster duties use different talents. Absence and conflicting duties matter. Do not assume appointing the highest visible skill guarantees the best outcome.

    The Royal Council has War Councilor, Spymaster, Economic Advisor, and Foreign Advisor seats. One person cannot occupy every major seat. Select the War Councilor through the War Council. Economic and Foreign Advisors must be eligible and available for residence at the capital.

    Ask the relevant advisor for a briefing or a fuller explanation. Advice is advisory: it does not issue a war order, pay a grant, change a treaty, or secretly settle a relationship. Only present participants share that council conversation.

    Preview: Royal Council residence, briefings, routing, and capital changes have implementation and interface evidence, but their full native/provider acceptance remains open.

    Economic reports and court supply

    Preview included#

    Open the Economic Report to inspect the realm's condition, including food and military burdens. Hover food information for reserve and projected-shortage explanations. Compare actual village output with healthy output; a town's full market is not the same as its settlement food reserve.

    Court transfers require actual stock, money, a valid route, and the necessary ownership or consent. A negotiated shipment is not free food. Spent resources and incoming cargo must be accounted for before you assume another grant is affordable.

    If workshop or caravan profit is marked unmeasured, read that as unavailable ledger information rather than zero earnings. See Economy and survival for how population, relief, and military costs interact.

    Authority and the ruler's limits

    Preview included#

    Government authority ranges from advice, through political pressure and reconsideration, to required approval for important decisions. At stronger levels the ruler may need a conscious override or a constitutional change; at the strongest level major actions can be blocked until approval is obtained.

    War, peace, treaties, policy, taxation, major spending, fiefs, and serious justice can fall within that authority. A valid military or diplomatic action is not permission to bypass Government. Relief and espionage have different classifications, but parties can still care about them.

    Increasing authority gives the institution a stronger role and brings public benefits. Reducing it through agreement differs sharply from forcing it down. Forced reduction can damage trust and relationships across the realm. An NPC's explicit consent protects only the person or clan they can actually represent, for the exact proposed change; it is not a permanent blank cheque.

    Joining Government without a crown

    Preview included#

    You can read public records, prepare proposals, approach members, and seek support before holding a seat. Admission depends on the institution. A noble seat needs actual qualifying clan leadership and land. A civic mandate needs an eligible constituency, endorsements, and the supported adoption and decision process.

    If a seat is occupied, its holder does not lose it merely because you ask. Transfer consent or a lawful recall route may be required. Political sponsorship cannot invent an extra seat, give you someone else's vote, or make you a vassal by implication.

    A member can vote, support proposals, join political work, and seek party responsibility. Membership does not grant treasury access, military command, or a Royal Council seat. A title such as Senator describes a real recorded office, not permission to direct the kingdom.

    Proposals, sponsors, parties, and sessions

    Preview included#

    Use Prepare a proposal and My Proposals where available. Choose the real kingdom, action or policy, target, and enactment or repeal terms. A draft is not a law. Changing its terms can require renewed support.

    In a supported conversation, Alt+A opens the action selector for political requests and the proposal route. Escape returns from the Government screen; inside the action builder it cancels that builder instead.

    Seek an eligible sponsor or party adoption. A willing member's personal support, a party's nomination, formal presentation, a vote, and actual enactment are separate stages. Speakers coordinate party work; they cannot turn their personal opinion into every member's ballot. An unused or unsupported nomination can expire rather than silently becoming law.

    Seats and future voting shares follow actual constituencies and territorial changes. A new holding can add representation; losing one can suspend it. Existing matters preserve their recorded voter roll rather than handing an absent member's vote to a newcomer. Crown and member weight also depend on the constitution, so do not assume every decision is a simple equal headcount.

    Hearings, recess, and political bargains

    Preview included#

    Public hearing speech enters the record but does not by itself spend gold, enact a policy, change a ballot, or create a private deal. Check attendance: absent members are not silently present in the conversation.

    For persuasion or a political bargain, speak with the actual available member in the supported individual conversation, including during a recess. There are no magical hearing buttons that guarantee a bought vote. Any accepted payment needs clear mutual terms, actual funds, and the right recipient. A deal depends on the promised obligation really being fulfilled.

    Political promises affect consideration; they do not guarantee every final vote. Read the recorded position and outcome. Changing your mind, missing a deadline, or failing an obligation can have consequences even if the original conversation sounded friendly.

    Resolutions, edicts, and follow-through

    Preview included#

    Government business spans relief, food and agriculture, trade, security, defence, war and peace, raids, espionage, diplomacy, justice, construction, prisoners and households, and taxes or obligations. An edict or policy can benefit one area while burdening another.

    Read the current target, completion route, deadline, and tradeoffs. Paying money is not always the same as supplying goods or improving an actual settlement condition. A promising speech does not complete a resolution; check the requirement and whether the game recorded it as fulfilled.

    Chapter 14

    Diplomacy, ambassadors, and Clan Accords

    Talking to the right authority

    Preview included#

    Rulers can negotiate war, peace, tribute, and longer agreements. NPC rulers also pursue their own policies according to personality, relationships, domestic pressures, current wars, and realm condition. You are not the only person capable of making the map change.

    A courtier can discuss an alliance without having power to grant it. An ambassador can negotiate only within their actual mandate. Ask who can decide, agree on the exact terms, and inspect the resulting agreement or native change.

    Use Alt+A in an eligible conversation to build a supported diplomatic action. For a written approach, open Correspondence with Ctrl+M, select the contact, then use Alt+A when the letter composer is ready.

    Political Pressure reflects friction or cooperation between realms and domestic lords. It can lead to peace, aid, trade, threats, or war. A ruler choosing foreign friendship may disappoint domestic supporters; supporting an angry noble faction may damage foreign relations.

    What agreements can do

    Preview included#

    Supported diplomacy includes ordinary and tribute peace, reparations, settlement concessions, surrender, trade, non-aggression, alliances, defensive pacts, independence guarantees, prisoner exchanges, ransoms, hostage guarantees, border restraint, caravan protection, supply, loans or subsidies, paid neutrality, paid war entry, and dependent political arrangements.

    Compound packages can link several terms. Review who pays, who gives up territory or prisoners, which enemy is named, the duration, and whether it is public. Some arrangements directly alter Bannerlord state; others record obligations enforced when relevant events occur. A promise of supplies is not an already completed shipment.

    An incompatible war can break treaties and damage trust. Peace does not necessarily recreate an agreement that ended. Temporary Truce and Trade Embargo are retired legacy action names; use the supported alternatives instead of assuming those old labels execute.

    Outbound and resident ambassadors

    Preview included#

    From Court's Ambassadors area, post an eligible ambassador, assign supported information, relations, or trade work, and recall them when appropriate. Postings occupy limited capacity and persist over time.

    A resident foreign envoy comes from another peaceful ruler to your capital. They travel, arrive, and reside there rather than appearing instantly. Capital movement can relocate the posting; war can recall it. An envoy's conversation and authority can pass to a successor without wiping the state's diplomatic history.

    An official envoy cannot grant something outside their charter, regardless of how persuasive you are. Refer an unauthorized request to the foreign ruler. Distinguish an ambassador's personal feelings from the terms they can officially approve.

    Clan Accords

    Preview included#

    Preview: Clan Accords have source and contract evidence; their complete installed native lifecycle still needs acceptance.

    Clan Accords are smaller cooperative arrangements between the player ruler's clan and an NPC clan. They are not kingdom treaties. A lesser eligible adult noble can arrange an accord for their clan through explicit agreement; it does not always require the clan leader to negotiate personally.

    Use Alt+A in the ready conversation to find the supported Clan Accord action. Escape closes the Clan Accords management screen.

    AccordPractical benefit

    Mutual WatchBetter security in owned towns and castles
    Agricultural exchangeHelp with village household growth

    Available slots grow with clan tier separately for each accord type. Benefits can stack, and a valid accord can begin helping new holdings acquired later. Review capacities, partners, arrangers, and benefits through the Economy entry beside the campaign date and its Clan Accords screen.

    Peaceful allegiance changes or an arranger's death need not end an accord. War with the partner's faction or clan elimination ends incompatible arrangements. Voluntary cancellation can hurt relationships; wartime termination has different rules. Peace afterward does not automatically sign them again.

    Accords can build goodwill but do not grant votes, military authority, or Spymaster access. Mutual Watch is cooperation, not a hidden unlimited intelligence-report service.

    Chapter 15

    Spymaster and covert work

    Appointing and using a Spymaster

    #

    Appoint an eligible Spymaster, then use Court's Spymaster tab. Roguery matters, alongside the person's overall fitness for office. There are limited concurrent missions, and an officeholder with active work cannot simply be replaced to erase its consequences.

    Choose the mission, actual target, and shown terms. Read cost, duration, difficulty, and risk of detection before starting. A routine mission and an assassination are very different commitments. An unavailable target can invalidate work, and spent money is not automatically refunded.

    Intelligence and sabotage

    #

    Intelligence work can investigate land, skills, relationships, rumors, and reputations. Counterintelligence searches for foreign agents. Sabotage can disrupt food contribution, construction, security, or loyalty for a period of time.

    Better expertise helps but does not guarantee success or secrecy. Important and well-protected targets are harder. Read the returned report: an attempt is not a successful disruption, and detecting activity is not always identifying its sponsor.

    NPC kingdoms can also disrupt food production in villages supplying an enemy town during wartime. This activity uses the NPC kingdom and runs alongside the Spymaster missions you choose. Its disruption wears off and food relief continues. Use Court's Economic Report to check food supplies when planning for a siege or shortage.

    Social manipulation and lethal missions

    #

    Supported social work can mitigate your own or another person's damaging signal, promote a positive reputation, or fabricate harmful allegations. An allegation can affect society without making it objectively true. Established reputations are harder to erase than rumors.

    Assassination can kill a unique person and expose or capture your Spymaster. A captured operative can require ransom or a personal breakout attempt; rescue can fail and place you in custody too. Read those consequences before confirming. Counterintelligence and ordinary information work are available without choosing a lethal mission.

    Foreign realms can recruit disaffected agents and operate against you. A friendly-looking court is not proof that every member is loyal. Exposed agents leave the active hidden pool while their history remains.

    Chapter 16

    Giving a clear campaign order

    Preview included#

    The Campaign Command Engine supervises accepted NPC party and army orders over time. It controls the commander's force, not your main party. You need legitimate authority or the commander's explicit agreement.

    Specify the commander, objective, target, duration or stop condition, and any troop or supply requirement. “Patrol around this town until I recall you” is different from “capture that castle.” A conditional reply or counteroffer changes the terms. Read the accepted version before confirming.

    Build the command with Alt+A in the supported conversation. For written orders or reports, open Correspondence with Ctrl+M and use Alt+A with the eligible commander selected.

    Orders can adapt to changing danger, war state, geography, and duties. A commander may report trouble, withdraw, refuse, or ask for guidance. Correspondence can carry those reports and their deadlines. Issuing the order does not mean it has already completed.

    War Council map and intelligence

    Peace Standing, War Standing, and garrisons

    Preview included#

    Preview: military standing and the revised war economy are actively being balanced and verified. Their goals are not a promised starvation timer or guaranteed food supply.

    The sovereign's Peace Standing and War Standing controls sit either side of the crowned R in the revised War Council. Automatic adjusts peace readiness to external pressure; a manual peace strength keeps your selected target. The Royal Docket's Kingdom Military Standing provides the corresponding orders.

    Peace standing limits automatic field recruitment. Peace drawdown selects eligible surplus healthy soldiers proportionally across troop tiers. This preserves more of the force's mix while the party shrinks. A safe subordinate lord party can release troops gradually. The main party, garrisons, heroes, and wounded troops are outside this drawdown. Current battles, army service, and a player-issued recruit and resupply order can prevent the drawdown. Released soldiers can help functioning village households recover.

    War standing still needs actual funds, recruits, and provisions. Garrisons keep defensive targets in either standing. Stationary garrison regulars cost less to supply and maintain than field troops; transferring them out returns them to field costs. Visiting parties do not gain that garrison discount.

    Inviting a noble to travel with you

    Preview included#

    Ask an eligible noble from another clan to accompany you temporarily. This is a Temporary Party Guest agreement, not companion recruitment, vassalage, or a clan transfer. Agree on purpose, risk, and a fixed or open-ended term. The noble can refuse.

    Use Alt+A in the ready conversation to build the guest request or supported revision/departure action. To speak with a guest already traveling with you, open Party Chat with backslash (\) and select them.

    A guest retains clan, identity, and equipment; their equipment cannot be treated as freely available inventory. If they led a party, their real original force remains as [Name]'s Waiting Camp, protected while the noble visits. Do not mistake the camp for an abandoned army to harvest.

    At review, Speak Now opens the discussion and Let Them Depart begins the return. Departure can require actual travel back to the original party or a safe alternative. Asking them to leave early still requires the supported agreement; a polite farewell is not proof of departure.

    War with their faction forces a separate risk review. Letting a guest fight their own people can lead to banishment and a permanent clan change, subject to succession safeguards. Read that decision carefully; ordinary guest acceptance alone does not authorize it.

    Chapter 17

    Duels, arrests, rulers, and civil war

    Choosing a duel

    Preview included#

    An eligible NPC can agree to a duel in individual conversation. Read the Bannerlord Reign Duel prompt before starting; cancelling the start is different from losing a fight.

    Use Alt+A in the ready individual conversation to select the supported duel request and terms.

    ModeWhat is at stake
    PracticePrivate, nonlethal sparring. The opponent remembers it, but it does not produce ordinary public duel glory, disgrace, or automatic relationship rewards.
    HonorA nonlethal challenge whose outcome can enter public combat history, news, and reputation.
    LethalA real death risk under the confirmed terms. Never treat it as ordinary practice.

    Nonlethal fights use protected health handling rather than normal campaign injuries. Duel training reduces health damage so combat can last longer while preserving a separate training-XP path; blocked hits can matter for learning too. It is not a way to apply those protections to an unrelated battle.

    The mission outcome decides who won. Narrating victory does not replace the fight. A duel used for an arrest has custody consequences and is separate from private practice. Existing native learning modifiers still affect actual skill gains.

    Arrests: accusation, confirmation, and custody

    Preview included#

    You need real jurisdiction: an eligible player-owned holding, an accused person in your party, or the supported encounter with their party. An insult in a distant conversation does not grant universal arrest power.

    Prepare an accusation with its reason, then explicitly confirm the arrest. These are separate steps. Reign considers cause and evidence; a serious unsupported accusation can hurt relationships and public standing. A rumor is not automatically a justified conviction.

    Use Alt+A for the supported prepare, confirm, release, or rescind action. Opening the selector does not itself order an arrest.

    During a party encounter, the accused can surrender or resist. A nonlethal arrest duel or native battle may follow. You gain custody only when the actual result places the person with you.

    Release frees the prisoner but retains the accusation. Rescind clears that accusation and its associated effect and releases the accused. Protected custody of your own realm's or clan's arrested people differs from ordinary random escape; deliberate release, death, and actual battle outcomes still matter.

    Captured rulers and sovereign judgment

    Preview included#

    Preview: expanded ruler capitals, capture protection, judgments, and settlement consequences have continuing native acceptance work.

    NPC rulers tend to remain at a secure capital until they can lead a substantial present army. They can relocate when a capital is lost and return after a campaign. These rules do not take away the player's freedom to travel. An army still approaching is not the same as soldiers already present.

    Defeating a ruler does not guarantee capture. When a sovereign is captured, the capturing sovereign has special decisions. A player vassal or mercenary does not acquire that sovereign power just by holding the prisoner; direct handover is distinct from a routine dungeon donation.

    Ordinary-war judgments can include an execution sentence, exile with concessions and a replacement ruler, or submission and annexation. Read the permanent political outcome and temporary settlement effects. Sentencing is not the same as actual death. During a pending sentence, normal sale or ransom cannot bypass it, but escape or rescue can cancel the pending outcome.

    An unauthorized vassal execution can anger both realms without granting the sovereign settlement package. The ruler feature also has life-and-death requirements; review its Options before assuming a no-death campaign preference will remain compatible. It changes no combat-death difficulty by implication.

    Rebellion and civil war

    Preview included#

    Disaffected NPC vassal leaders can begin a rebellion, and other clans choose sides. A non-ruling player vassal can also seek a rebellion through an accepted supported action. A promise of sympathy is not a clan transfer; a recruited lord must explicitly accept.

    A rebel realm is a real political faction. Capture, death, surrender, and rulership determine its decisive outcomes; an unrelated foreign power capturing a leader is not automatically victory for either civil-war side. Ordinary peace cannot simply skip the special resolution.

    Secret support for a future rebellion is distinct from joining one already declared. A pledge can bind a named clan to the challenge against a particular ruler while its current allegiance remains in place. Informers, refusals, summons, renunciation, and defiance can all become part of that political history.

    The later ruler-judgment flow distinguishes recognized rebel independence, execution under its sentence rules, and reunification under a victorious rebel leader. Loyalist victory can lead to freedom, imprisonment, or execution judgments for defeated leaders. These are substantial campaign choices and can affect the player as well as NPCs.

    Civil-war outcomes differ from ordinary conquest. Do not assume an ordinary-war annexation or settlement-effect package applies to a rebellion. Pending judgments and the sequence of decisions survive saving; inspect the remaining queue rather than assuming the first ruling resolved everyone.

    Chapter 18

    Economy and survival

    Troops cost more than in native Bannerlord

    Preview included#

    Recruiting, upgrading, and maintaining a strong army is more expensive in Reign, especially as troops become more advanced. A field army that you can buy today may still be unaffordable to keep supplied. Native perks and discounts still matter; negotiated hero or guest pay follows its own agreement.

    Automatic recruitment and upgrading consider the actual payer's funds and future military obligations. Having spare kingdom wealth does not necessarily mean every clan can replenish. Manual player purchases still require real resources, without implying that every automatic safety buffer is a new player spending rule.

    Prisoner ransoms follow native valuation rather than inheriting the increased enlistment price. Releasing or selling prisoners is not a way to recover the full cost of building an elite force.

    Preview: current war-economy revisions have controlled and persistence evidence, but long-run balance and human acceptance remain open. Descriptions here explain the reviewed rules, not guaranteed outcomes for every kingdom.

    The higher wage base applies to regular troops in field parties and garrisons. The owned-party wage display accounts for that party's actual modifiers and discounts. Recruitment previews use the receiving party's forecast where available.

    Kingdom regulars cost a little more while their realm is at war with another kingdom and a little less at peace. This applies to both field and garrison wages after existing modifiers. Hero salaries, mercenary troops and companies, and independent clans are outside this particular adjustment. See War economy and clan trade settings to adjust the available cost rules.

    Recruitment uses people, not an endless pool

    Preview included#

    New regular military recruits draw from eligible village households. Heavy recruitment leaves fewer people available and slows natural household growth for a while. A depleted or badly damaged village may be unable to supply more soldiers even when you have gold.

    This applies to player and AI recruitment and to supported automatic garrison and replacement-retinue routes. Existing soldiers are not retrospectively charged when the economy update arrives. Creating a new lord party does not grant a free fully funded army: its household troops depend on local people and actual money.

    Transferring soldiers, returning an expedition, upgrading an existing troop, or recruiting a prisoner is different from a new enlistment. Native mercenaries and special quest routes have their own handling. Civilian caravan and fishing crews do not consume village military manpower merely by being created or replenished.

    For automatic lord-party creation in NPC-ruled kingdoms, a noble clan generally needs land. Hired mercenaries can establish a party without land. Kingdom military support requires both land and an active serving lord party. Player-directed establishment and native initial or quest routes have their own rules. A landless household can still qualify for local stipends or civilian trade under Household stipends and NPC trade.

    Household stipends and NPC trade

    Preview included#

    A landless NPC noble household with a verified permanent home may receive a small weekly stipend from the clan leader who owns that holding. Eligibility looks at the family's finances, the current owner, shared kingdom, and the payer's ability to keep a military reserve. To let your own clan participate, enable Fund Local Household Stipends in Reign's in-game settings. Payments use your personal gold.

    The installed land caravan pilot lets eligible landed and landless NPC clans sponsor standard caravans. Turn it on through Enable NPC Caravan Investment Pilot in Reign's MCM. It starts off and assigns a named captain. It charges the clan for both formation and working capital and checks that enough cash remains for military needs. The caravan trades and remits money through native Bannerlord. Loss can cost the clan its investment.

    Preview: the NPC Clan Trade revision has passed its Options browser checks and is awaiting final release validation. It adds land caravans and War Sails sea convoys with a suitable port. The sponsoring clan pays one formation fee and retains ownership and trade remittances. Bannerlord supplies the starting trade purse separately. New parties use merchant crews without assigning a named noble captain. Existing pilot caravans keep their captains and records.

    The separate land and sea controls are described in War economy and clan trade settings under the revision notice.

    Raids, population, and recovery

    Preview included#

    Village households support production. Healthy larger villages contribute more, while devastation reduces actual output. A completed raid resets agricultural recovery; normal functioning and safer, better-fed conditions allow it to recover gradually.

    A raid's damage does not end when the smoke disappears. Several damaged villages can place separate security burdens on their linked town. Recruiting may remain restricted during early recovery. A village that is not functioning cannot be assumed to produce food or recover normally.

    Siege aftermath matters too. Mercy is less damaging to security than pillage or devastation. Choosing the harsher option has a continuing cost, not just a different line in the victory report.

    Raid damage now has its own food capacity measure alongside household recovery. Severe or repeated raids can shut down new food production. A functioning village recovers gradually, and low food or security slows that recovery. Open the Economic Report from Court to compare food capacity, household recovery, actual output, and healthy potential for the current population.

    In fishing villages, disruption reduces new catches from boats and shore facilities. Fish already carried remain in cargo. A working voyage can finish and unload. When the village's fishing capacity shuts down, boats unload before waiting ashore. Recovery allows another departure. Food shipments and relief use their own rules. Control Center → Options → War economy → Raid food disruption keeps recorded damage available for when you turn the rule back on.

    Food markets, settlement stocks, and relief

    Preview included#

    Distinguish food offered in a market, food held by a settlement, food carried by an army, and cargo in transit. They are not the same stockpile.

    Threatened unsieged towns prioritize buying available food within their civilian budget. They cannot buy food that does not exist or spend unlimited money. Realm relief moves real food from eligible better-supplied holdings toward shortages while protecting donor reserves. It prioritizes serious projected need and loses some food along the route.

    Sieges can block purchases and deliveries. A manual shipment deducts stock when dispatched, takes time, and can be held outside a newly besieged destination while cargo deteriorates. Food traveling between holdings is not immediately available at both ends.

    Granary actions, normal market buying, automatic relief, and a court grant are separate mechanisms. Inspect the Economic Report's current reserve and projected trend before assuming a shipment solved a deficit. Relief can ease hunger without making a besieged or devastated realm self-sufficient.

    Garrisons, patrols, and demobilization

    Preview included#

    Stationary garrison regulars have lower wage and food burdens than equivalent field troops. Native governor, culture, building, Billeting, and Clan Accord effects retain their own benefits and costs. A patrol or visiting army does not receive the new garrison reduction just for being nearby.

    Patrols use troops transferred from the home garrison. Replenishing them returns survivors before issuing another detachment. Removing a patrol outside combat returns its soldiers where supported; it does not create a fresh free roster.

    Peace drawdown can return some released manpower to functioning villages, while raids and mobilization strain still matter. It provides no automatic gold payout or instant prosperity. Keep defensive needs and actual household recovery in view when changing standing.

    Battle medical discharge

    Preview included#

    Some regular soldiers newly wounded in battle can retire if they survive the battle without being captured and remain with the force they fought in. The result varies each battle. Better surgeon Medicine lowers the maximum possible loss. Previously wounded troops, captured soldiers, heroes, and civilian crews are outside this discharge rule. Rescue or release does not make a captured soldier eligible from the earlier battle.

    Eligible retired soldiers can contribute back to functioning village households. This is separate from peacetime release of healthy soldiers. See Peace Standing, War Standing, and garrisons for peacetime release. Medical discharge is installed. Individual battle and reload edge cases remain under review.

    Ships, ports, and military purchases

    Preview included#

    Where War Sails is present, player ship purchases, repairs, and upgrades retain native pricing. NPCs retain their native discounted ship procurement. A cheaply procured NPC ship does not become a full-value resale windfall simply because it was transferred to a friend. Captured ships retain their separate normal native resale handling.

    Selling needs actual port funds. A sinking, discarded hull, or cleanup removal does not pay compensation. Governor commissions come from real eligible port business and cannot exceed the transaction. Existing ships without a known acquisition history use the documented migration handling instead of an invented past battle or purchase.

    Automatic military food and mount purchases in the payer clan's own realm still pay the market, but do not create an extra tariff payment back into that realm through the old loop. Ordinary trading and foreign purchases retain their own rules. This is a targeted accounting change, not a general abolition of tariffs.

    Chapter 19

    Time, news, and world events

    A longer calendar and new-campaign differences

    #

    Reign's year and seasons last longer than native Bannerlord's, and character aging follows that calendar. Existing campaigns receive anchors so adopting the calendar does not suddenly change everyone's apparent date or age. Read the game's actual dates and agreed deadlines rather than counting native-length years from memory.

    New campaigns also include a deeper younger generation in eligible noble families and authored starting-age adjustments for Rhagaea and Ira. These are new-campaign setup changes; an update does not reseed children or overwrite ages in an established save. Newer narrative profiles likewise do not silently replace the life stories of old campaigns.

    Background world motion begins after the initial preparation grace period. Political incidents, court business, relationships, and rare kingdom events need actual campaign time. Waiting for a cloud response in a paused conversation is not the same as advancing the calendar.

    Arena Overhaul is included

Team Practice adds coordinated teams. Supported modes can let you play as a companion hero, and some can give viewing heroes experience when enabled.

Reign's party-member team handling aims to let eligible accompanying heroes fight with you while keeping them out of opposing teams when you compete.

    Pictures, appearance, and memories

    Portraits and Look at them

    #

    Reign can display persistent portraits across its own screens and supported native surfaces. Shipped characters can use the shared library; dynamic people and changed appearances can use campaign-specific pictures. A missing picture does not mean the person has no identity or history.

    Use portrait zoom for a larger view and Look at them for the supported appearance description and refresh choices. New portrait generation follows the configured image provider. It is separate from simply viewing a cached image.

    Current appearance and equipment matter, especially for encountered residents. A civilian's work clothes should not silently turn into noble costume just because a portrait was requested. Normal/adult image-profile settings and outfit changes have their own boundaries; they do not grant new gameplay authority.

    The shipped shared library is in the installed Reign module under PortraitCache/_shared. Campaign-generated portraits live in the managed ReignServer data/PortraitCache folder, grouped by campaign identity. Saves from the same campaign share that campaign's portrait folder.

    View in individual or Party Chat can request an illustration of the current scene. It uses the current conversation and relevant people as context; the resulting image can appear in the transcript and open larger. It is optional cloud image work, not an automatic screenshot of the native scene.

    An image can help you visualize a situation but cannot prove that a gift was delivered, a person arrived, or a battle occurred. If clothing is being changed, use the supported before/after preview and keep/revert choices rather than treating a generated picture as a completed equipment transfer.

    The Memory Book

    #

    Open Memory Book from the quest interface to browse illustrated memories. The book combines recorded experiences with optional artwork. Navigate the list and selected scene rather than expecting it to be a conventional quest objective list.

    An illustration is a visual interpretation of stored events. Changing or deleting a picture does not rewrite the original experience, promises, or world history. A fact can remain remembered without having an illustration.

    Small interface and native-behavior changes

    #

    Reign replaces supported main-menu logo/video presentation and uses its black-marble court style across major screens. It preserves usable native skill information, banners, and quest markers while hiding exact NPC relationship values.

    Narrated actions in supported conversation responses use italic treatment to help separate them from speech. The action builder's protected sentence has its own presentation. Neither formatting style means an action already happened.

    Reign-owned popups support consistent Enter/Escape behavior. Safety repairs also handle an encyclopedia interface disappearing during a tick, delayed native relocation races, and map-bar input during unavailable states. These are quiet stability changes rather than new player commands.

    NPC-owned settlement dungeons receive the same native prisoner-holding advantage as player-owned ones. Noble prisoners may therefore remain in AI custody more reliably. The foreign-governor loyalty penalty is removed by the ruler integration, while foreign ownership and matching-governor benefits retain their separate effects. Those two culture rules should not be confused.

    Chapter 22

    Saving, loading, and backups

    A Bannerlord save and Reign memory belong together

    #

    Your native save holds Bannerlord's campaign. Reign also stores memories, relationships, history, images, and other campaign state in its local server. Save Sync pairs a protected native save with the matching Reign snapshot.

    Save with the server running. Reign prepares the matching snapshot and warns if the native save succeeds but server protection fails. An unprotected save is still a native save, but it is not proof that the matching Reign state is safely aligned. Restore service and make a new protected save rather than ignoring the warning.

    Copying or renaming a native save does not invent a fresh Save Sync identity. Loading an older protected point restores the associated Reign timeline; later memories should not bleed into an earlier world.

    Capacity and safe housekeeping

    #

    There is a limited pool of unique protected Save Sync states. Watch the warning and capacity display instead of keeping unlimited one-off saves and assuming every one is protected. Overwriting an ordinary rolling save can retire its older point where safe. Use the native save UI's supported deletion flow when removing a save you no longer need.

    Do not manually delete server database folders to make space. A native save can exist without its matching protected Reign point, and a renamed copy can still share the old identity. Keep intentional backups outside routine cleanup.

    Close Bannerlord before using the Control Center's Campaign Backups cleanup controls. Choose the individual campaign, campaigns with no matching saves, or the full cleanup option, then answer the Are you sure? prompt. The no-save cleanup preserves campaigns with matching physical saves, imports awaiting their first load, and the shared portrait library. Full cleanup removes Reign histories, backups, campaign portraits, and related queued work. The native save files and installed shared portraits remain. An already scheduled cleanup can finish after the server starts.

    Exporting and restoring a campaign

    #

    In Campaign Backups, select the correct campaign and export its archive. Keep the matching native Bannerlord save with it. The Reign archive preserves campaign-side memory and supporting data; it does not contain your global provider API keys.

    On restore, select the intended archive and inspect any replace-existing-campaign warning before confirming. Loading a native save from one point with unrelated server data is not a complete restoration. Keep a separate copy of the current pair before replacing anything valuable.

    Deleting a Reign campaign is destructive even if it leaves the native save file behind. Deleting all campaigns is broader still. A backup, a protected snapshot, an older native save, and a new campaign are four different things.

    Updating, moving computers, and removing the mod

    #

    Before a major update or move, export Reign campaign data and retain the matching native save and package/version information. The installation's module, writable cache, selected server environment, and shared portrait library have deliberate locations; copying only a DLL is not a complete installation.

    Existing campaigns keep established identities and profiles unless an explicit supported migration changes them. Do not assume a new-campaign feature will be retrofitted. Likewise, do not assume removing a mod with saved campaign behaviors mid-campaign is supported. This guide does not claim a tested universal uninstall or cross-version save-conversion path.

    Help, glossary, and edition notes

    Chat is slow or not answering

    #

    Check that the launcher-managed server is healthy, the selected cloud LLM provider is configured and available, and the game points to the installation's correct local URL. Initial character preparation can take longer than a warm conversation. A long cloud response does not prove your graphics card is too weak.

    Keep the pending operation's status in view. Reopening may recover a result already being generated. If the request clearly failed, use its retry path; do not send many copies of the same request or change every provider setting at once. If reporting it, keep the error, approximate time, NPC, conversation surface, and relevant diagnostics.

    The NPC agreed, but nothing happened

    #

    Check the attached action or agreement status, execution settings, actual target, funds, inventory, ownership, presence, authority, and safety. The accepted terms may involve a future date or physical travel. A new counteroffer can mean you have not yet accepted the final version.

    For a guide, follow them. For a departing guest, allow the return journey and inspect the agreement. For a government proposal, check adoption and the actual vote rather than its draft. For a shipment, check cargo and access. These are different failures and should not all be fixed by repeating “yes.”

    A menu, person, or picture is missing

    #

    Check eligibility first. Court needs rulership and appropriate location; a full Royal Court needs a capital. Homes lists known available residents. Party Chat uses available eligible people. A pregnant NPC may be withdrawn. An ambassador can still be traveling or recalled.

    For pictures, distinguish cached display from new generation. Check Enable AI Portraits and the relevant scene switch, then the separate cloud image settings. Missing optional artwork should not be treated as a missing character. A Preview feature may also differ between the reviewed source and your installed package.

    Saving warns, preparation stalls, or a rollback seems wrong

    #

    Keep the native save. Read whether it is protected or unprotected, whether capacity is full, and whether the server is reachable. Re-establish the matching services and use a protected save or known matching backup pair. A successful native save alone does not establish that all Reign data was captured.

    Use preparation Retry for a recorded failed stage. Do not delete database folders or invent a new campaign to bypass a recoverable stage. If an older save appears to know future events, preserve the save and diagnostic evidence and report a timeline-alignment problem rather than continuing to overwrite your only good pair.
